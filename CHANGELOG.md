# Changelog

## Version 1.0.2 (2026-11-16)

- Large controller compatibility pass. Should now work nicely.
- Reworked the Uninstall button. It now lives properly in the Settings window. Credit to Road & Rail Upgrade Brush mod for demonstrating the button trick.
- Fixed missing legend (bottom right key/button guide).

## Version 1.0.1 (2026-11-15)

- There was previously no limit to how far the priority road would extend, with no way to control it either. It now only applies to junctions that are on-screen in the default mode (no modifier key/button).
- Added Shift-click to apply to/remove from individual junctions.
- Added Ctrl-click to enable infinite reach.
- Improved some tooltips.

## Version 1.0.0 (2026-11-15)

- First release.
