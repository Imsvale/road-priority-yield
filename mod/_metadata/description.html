Cars in Transport Fever 3 never yield: at a roundabout entering cars cut in and the ring backs up, and side roads push into main roads.

Priority Road (Roads > tools): click a road or a roundabout. The tool follows it through its junctions and makes every side road yield to it, using invisible traffic lights: the priority road stays green while it has traffic, side roads go when there is a gap. In a paired test on a roundabout, stopping on the ring dropped by 96% and the ring no longer broke down. Click again to remove.

Also: an invisible traffic light type for your own setups.

Savegame compatibility

  • An Uninstall tool is provided to remove all traces of the mod from the save, if you want to remove the mod. Find it in the Priority Road tool's settings: tick Uninstall and click Remove all.
  • If this is not run before removing the mod:
    • Load warning: Sign models will be replaced with placeholders.
    • If a road near a previously handled junction is changed, it will try to find the "invisible traffic light" the mod used, fail, and the game will crash with an Internal Error. (Suggestion to devs: Revert to index 1 or 2 if an index access is out of bounds.)
  • If you have run the uninstall tool, you can safely ignore the warning the game gives you upon deactivating the mod.
